## 2. Product Scope & Current Functionality
### 2.1 Visualization & Math Capabilities
- Legacy VIB34D engines (faceted, quantum, holographic, polychora) are still parameter-driven but now consume quaternion inputs via the adaptive runtime.【F:README.md†L7-L39】【F:DOCS/1-TECHNICAL-OVERVIEW.md†L70-L126】【F:src/core/AdaptiveInterfaceEngine.js†L22-L55】

### 2.2 Interaction, Localization & Storytelling
- `SensoryInputBridge` normalizes focus, gesture, biometric, and ambient channels with adapter lifecycle hooks, validation logs, and historical buffers suitable for wearable inputs.【F:src/ui/adaptive/SensoryInputBridge.js†L1-L160】【F:DOCS/PHASE_ZERO_DISCOVERY_REPORT.md†L16-L33】
- `SensorSchemaRegistry` provides reusable schema validators, composite wearable ingestion, and numeric sanitation so heterogeneous payloads can be trusted before localization.【F:src/ui/adaptive/sensors/SensorSchemaRegistry.js†L1-L200】
- The localization fabric (`LocalizationBridge`, `QuaternionFabricRouter`, `RotorFusionService`, `PredictiveRotorCache`, `SpatialStoryGraph`) derives dual quaternions, maintains channel priorities, fuses confidence, forecasts future rotors, and triggers story graph reactions for XR experiences.【F:src/ui/adaptive/localization/LocalizationBridge.ts†L1-L200】【F:src/ui/adaptive/localization/QuaternionFabricRouter.ts†L1-L134】【F:src/ui/adaptive/localization/RotorFusionService.ts†L1-L140】【F:src/ui/adaptive/localization/PredictiveRotorCache.ts†L1-L192】【F:src/ui/adaptive/localization/SpatialStoryGraph.ts†L1-L200】
